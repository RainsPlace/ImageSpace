Replay Poker messages support Markdown formatting. Here’s everything you need to embed images, style text, and build polished tournament announcements directly in a private message.

🖼
Embedding an ImageThe core syntax — one line is all it takes
Syntax
![description](image URL)
Example
![Early Bird Banner](https://raw.githubusercontent.com/RainsPlace/Avatars/main/Early%20Bird/EB1.jpg)

When the recipient opens the message, the image appears inline in the message body — no link, no attachment, just the image.

The DM button under every image in this gallery copies exactly this format for you, with the correct filename and URL already filled in. Just paste it into your message.
📋
Rules to KnowFour things that will save you troubleshooting time
  • Direct image URL only. The URL must point straight to the image file — not a webpage that contains an image. GitHub raw links (raw.githubusercontent.com/…) work perfectly. A link to a GitHub file page or Google Drive preview will not work.
  • No HTML. Do not use <img src="…"> — Replay strips all HTML tags silently. You will see nothing, with no error message.
  • No size control. There is no way to set a width or height in Replay Markdown. The image renders at its natural/original size. If it looks too big or too small, the source image file itself needs to be resized before uploading.
  • Spaces in URLs must be encoded. Replace every space with %20. Example: My Image.jpg → My%20Image.jpg. Images from this gallery already have correct URLs — the DM button handles this automatically.
